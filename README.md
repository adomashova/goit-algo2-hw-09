## Що реалізовано

Мінімізація функції Сфери `f(x) = Σ xᵢ²`, `xᵢ ∈ [-5, 5]`
(глобальний мінімум — точка `(0, ..., 0)`, значення `0`).

Усі три алгоритми повертають кортеж `(точка, значення_функції)`,
працюють суворо в межах `bounds` (координати обрізаються до меж) і
приймають `iterations` — максимальну кількість ітерацій.

| Функція | Ідея | Умови завершення |
|---|---|---|
| `hill_climbing` | Перебирає сусідів (±крок по кожній координаті), переходить до найкращого; якщо покращення немає — зменшує крок удвічі | вичерпано `iterations`; крок < `epsilon`; зміна значення функції або положення точки < `epsilon` |
| `random_local_search` | Генерує випадкового сусіда поточної точки, приймає його лише якщо він кращий | вичерпано `iterations`; прийняте покращення < `epsilon` |
| `simulated_annealing` | Гіршого сусіда приймає з імовірністю `exp(-Δ/T)`; температура падає `T *= cooling_rate`; крок пошуку зменшується разом з температурою; повертає найкращу знайдену точку | вичерпано `iterations`; температура < `epsilon` |

Параметри за замовчуванням — з шаблону завдання:
`iterations=1000`, `epsilon=1e-6`, `temp=1000`, `cooling_rate=0.95`.

## Як протестувати в терміналі (VS Code)

```bash
python3 local_search.py
```

Зовнішні бібліотеки не потрібні (лише стандартні `random` і `math`).

Очікуваний вивід (числа відрізнятимуться при кожному запуску, бо
алгоритми випадкові, але порядок величин має бути таким):

```
Hill Climbing:
Розв'язок: [0.00018..., -0.00011...] Значення: 4.7e-08

Random Local Search:
Розв'язок: [-0.00051..., -0.00186...] Значення: 3.7e-06

Simulated Annealing:
Розв'язок: [-0.00261..., 0.00065...] Значення: 7.3e-06
```

Що перевіряти: обидві координати мають бути близькими до `0`, а
значення функції — дуже малим (зазвичай `< 0.01`; Hill Climbing —
найточніший, `~1e-7`).

## Висновки про методи

- **Hill Climbing** — найшвидший і найточніший на гладкій опуклій
  функції (Сфера має єдиний мінімум), але на функціях з багатьма
  локальними мінімумами може застрягти в першому ж.
- **Random Local Search** — простіший, не потребує перебору всіх
  сусідів, але збігається повільніше й менш точно.
- **Simulated Annealing** — може вибиратися з локальних мінімумів
  завдяки прийняттю гірших розв'язків, але на такій простій функції це
  зайве: результат стохастичніший і трохи менш точний за Hill Climbing.
  Його перевага проявляється на складних функціях із багатьма мінімумами.
